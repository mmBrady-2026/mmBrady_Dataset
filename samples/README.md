# mmBrady Dataset Sample

A random sample of 10 windows from the mmBrady dataset, containing processed radar data, 14-dimensional standardized IMU features, window-level activity and movement-stage labels, and clinical bradykinesia scores.

Array shapes, feature order and label codes: `metadata.json`. Loading example: `load_example.py`.

For methodology and dataset details, see *Contactless Upper-Limb Bradykinesia Monitoring for Parkinson’s Disease via Semantic-Aware mmWave Sensing in Daily Life*.
