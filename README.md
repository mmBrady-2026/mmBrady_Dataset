# mmBrady Dataset

This repository contains only a sample of 10 windows, including processed radar data, 14-dimensional standardized IMU features, window-level activity and movement-stage labels, and clinical bradykinesia scores.

Browse [samples](samples), [metadata](samples/metadata.json), the [loading example](samples/load_example.py), and the [dataset use agreement](samples/mmBrady_Agreement.pdf).

For methodology and dataset details, see *Contactless Upper-Limb Bradykinesia Monitoring for Parkinson’s Disease via Semantic-Aware mmWave Sensing in Daily Life*.

To request the full dataset, please complete and sign the [Dataset Use Agreement](samples/mmBrady_Agreement.pdf) and email it to the author at [jwangjx@connect.ust.hk](mailto:jwangjx@connect.ust.hk). Access to the full dataset will be provided after the signed agreement has been reviewed and approved.
